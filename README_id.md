 # Pado Wave Editor

<p align="center">

**Editor Gelombang Audio Profesional untuk Windows**

Editor audio yang cepat, presisi, dan andal untuk Windows.
Edit file audio dengan fitur profesional seperti pengeditan bentuk gelombang, visualisasi spektrogram, analisis frekuensi FFT, filter audio, dan alat perekaman.

</p>

---

# Unduh

Unduh penginstal terbaru dari halaman **Releases**.

Saat menjalankan penginstal, **Microsoft Store** akan terbuka secara otomatis dan menginstal versi resmi terbaru dari **Pado Wave Editor**.

---

# Fitur

* Pengeditan bentuk gelombang profesional
* Mesin pemrosesan audio berperforma tinggi
* Pengeditan multikanal
* Filter high-pass dan low-pass
* Analisis spektrogram
* Analisis frekuensi FFT
* Zoom presisi tinggi
* Pemutaran waktu nyata
* Perekaman audio
* Mendukung file audio berukuran besar
* Dioptimalkan untuk Windows 10 dan Windows 11
* Pembaruan otomatis melalui Microsoft Store
