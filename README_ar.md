# Pado Wave Editor

<p align="center">

**محرر احترافي للموجات الصوتية لنظام Windows**

محرر صوت سريع ودقيق وقوي لنظام Windows.
يتيح لك تحرير الملفات الصوتية باستخدام أدوات احترافية، بما في ذلك تحرير الموجات الصوتية، وعرض المخطط الطيفي (Spectrogram)، وتحليل التردد باستخدام FFT، وفلاتر الصوت، وأدوات التسجيل.

</p>

---

# التنزيل

قم بتنزيل أحدث برنامج تثبيت من صفحة **Releases**.

عند تشغيل برنامج التثبيت، سيتم فتح **Microsoft Store** تلقائياً وتثبيت أحدث إصدار رسمي من **Pado Wave Editor**.

---

# الميزات

* تحرير احترافي للموجات الصوتية
* محرك معالجة صوت عالي الأداء
* تحرير متعدد القنوات
* مرشحات الترددات العالية والمنخفضة (High-pass / Low-pass)
* تحليل المخطط الطيفي (Spectrogram)
* تحليل التردد باستخدام FFT
* تكبير وتصغير عالي الدقة
* تشغيل فوري في الوقت الحقيقي
* تسجيل الصوت
* دعم الملفات الصوتية الكبيرة
* مُحسَّن لنظامي Windows 10 وWindows 11
* تحديثات تلقائية عبر Microsoft Store

4. ثبّت **Pado Wave Editor**.
