# Pado Wave Editor

<p align="center">

**Editor profissional de formas de onda de áudio para Windows**

Um editor de áudio rápido, preciso e poderoso para Windows.
Edite arquivos de áudio com recursos profissionais, incluindo edição de formas de onda, visualização por espectrograma, análise de frequência FFT, filtros de áudio e ferramentas de gravação.

</p>

---

# Download

Baixe o instalador mais recente na página **Releases**.

Ao executar o instalador, a **Microsoft Store** será aberta automaticamente e instalará a versão oficial mais recente do **Pado Wave Editor**.

---

# Recursos

* Edição profissional de formas de onda
* Mecanismo de processamento de áudio de alto desempenho
* Edição multicanal
* Filtros passa-altas e passa-baixas
* Análise por espectrograma
* Análise de frequência FFT
* Zoom de alta precisão
* Reprodução em tempo real
* Gravação de áudio
* Suporte para arquivos de áudio de grande porte
* Otimizado para Windows 10 e Windows 11
* Atualizações automáticas pela Microsoft Store

# Instalação

1. Baixe **Pado.Wave.Editor.Installer.exe**.
2. Execute o instalador.
3. A Microsoft Store será aberta automaticamente.
4. Instale o **Pado Wave Editor**.
