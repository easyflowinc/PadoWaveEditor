# Pado Wave Editor 2.0

### 소리를 눈으로 보면서 자르고, 붙이고, 다듬는 무료 오디오 편집기

목소리 녹음, 노래 연습 파일, 영상에 넣을 효과음까지. 파일을 창에 끌어다 놓으면 바로 파형이 뜨고, 원하는 구간을 드래그해서 자르고 페이드를 걸고 저장하면 끝이에요. 처음 써 보는 사람도 헤매지 않게 흐름을 단순하게 만들었어요.

**무료** · **Windows 10 · 11** · **WAV · MP3 · FLAC · OGG · MIDI** · **14개 언어** · **라이트 · 다크 테마**

[Microsoft Store에서 받기](https://apps.microsoft.com/detail/9nj5928hw9pw) · [자세한 설명과 자주 묻는 질문](https://easyflow.co.kr/F/Doc/PadoWaveEditor/ko) · [이전 버전(1.0) 소개 보기](v1.0/README_ko.md)

## 이럴 때 딱이에요

- 🎙️ **목소리 녹음 다듬기** — 팟캐스트, 발표, 음성 메모에서 말실수와 긴 침묵을 잘라내고 소리 크기를 고르게 맞춰요.
- 🎧 **두 테이크 비교** — 두 파일을 좌우로 나란히 띄워 같은 구간을 번갈아 들으며 더 나은 쪽을 골라요.
- 🎹 **MIDI를 오디오로** — MIDI 곡을 열면 바로 연주돼 파형으로 떠요. 다듬어서 WAV나 MP3로 저장하세요.
- 🎮 **게임 · 영상 효과음** — 레이저, 폭발, 알림음 같은 효과음을 프리셋에서 골라 몇 번의 클릭으로 만들어요.
- 🎼 **연주를 악보로** — 녹음한 연주에서 음표를 찾아 악보로 보여 줘요. 음표를 클릭하고 화살표 키로 위치 · 음높이 · 길이를 고치거나 Delete로 지운 뒤 MIDI 파일로 저장해요.
- 🔍 **소리 들여다보기** — 스펙트로그램과 주파수 분석으로 잡음이나 튀는 소리가 어디 있는지 눈으로 찾아요.

## 세 단계면 끝

1. **열기** — 파일을 창에 끌어다 놓거나 Ctrl+O. WAV, MP3, FLAC, OGG, MIDI 모두 열려요.
2. **고르고 다듬기** — 파형을 드래그해 구간을 고르고 잘라내기, 페이드, 효과를 적용해요. 실수해도 Ctrl+Z면 돌아와요.
3. **저장** — Ctrl+S로 저장하거나 원하는 형식으로 내보내요.

## 기능 둘러보기

### 01. 멀티채널 파형을 한눈에 보며 오디오를 편집하는 메인 작업공간

<p align="center">
<img src="images/03-main-workspace.webp" width="100%" alt="멀티채널 파형을 한눈에 보며 오디오를 편집하는 메인 작업공간">
</p>

위쪽의 큰 파형에서 편집하고, 아래쪽 개요 막대로 파일 전체 중 어디를 보고 있는지 한눈에 알 수 있어요. 파일 정보, 재생 위치, 선택 길이는 파형 바로 아래 정보 줄에 늘 떠 있어요. 긴 파일도 파형을 먼저 빠르게 보여 주고 세부는 나중에 채워서 오래 기다릴 일이 없어요.

### 02. 전체 채널을 함께 또는 한 채널씩 선택해 정밀 편집

<p align="center">
<img src="images/05-channel-editing.webp" width="100%" alt="전체 채널을 함께 또는 한 채널씩 선택해 정밀 편집">
</p>

스테레오라면 왼쪽(위)과 오른쪽(아래) 채널을 함께 고를 수도, 한쪽만 고를 수도 있어요. 한쪽에만 들어간 잡음을 지우거나 한 채널에만 페이드를 거는 식으로 섬세하게 손볼 수 있어요.

### 03. MIDI 파일을 기본 제공 음원으로 연주해 파형으로 열고 편집

<p align="center">
<img src="images/02-midi-as-waveform.webp" width="100%" alt="MIDI 파일을 기본 제공 음원으로 연주해 파형으로 열고 편집">
</p>

MIDI 파일(.mid · .midi · .rmi)에는 소리가 아니라 음표가 들어 있어요. 열면 기본 제공 음원(MuseScore General)으로 연주해 파형으로 보여 주니, 일반 오디오처럼 자르고 효과를 넣어 WAV나 MP3로 저장하면 돼요. 더 마음에 드는 SF2 · SF3 음원이 있으면 옵션에서 바꿀 수 있어요.

### 04. 효과, 필터 및 분석 도구로 소리를 조정하고 확인

<p align="center">
<img src="images/04-effects-analysis.webp" width="100%" alt="효과, 필터 및 분석 도구로 소리를 조정하고 확인">
</p>

이퀄라이저, 필터, 컴프레서, 정규화 같은 효과를 고른 구간에만 걸 수 있어요. 그래프의 점을 끌어 소리를 바꾸고, 이퀄라이저 설정은 10개까지 저장해 두었다가 다시 불러올 수 있어요.

### 05. 리전, 큐, 레이어 및 스펙트로그램 패널로 빠르게 탐색

<p align="center">
<img src="images/06-panels.webp" width="100%" alt="리전, 큐, 레이어 및 스펙트로그램 패널로 빠르게 탐색">
</p>

이름과 색을 붙이는 리전, 위치를 표시하는 큐, 처리 결과를 켜고 끄며 비교하는 레이어 덕분에 긴 파일에서도 길을 잃지 않아요. 스펙트로그램은 소리를 주파수별 색으로 보여 줘서 잡음이나 튀는 소리를 눈으로 찾을 수 있어요.

### 06. 수백 가지 수식 기반 프리셋으로 만드는 효과음 생성기

<p align="center">
<img src="images/07-sfx-generator.webp" width="100%" alt="수백 가지 수식 기반 프리셋으로 만드는 효과음 생성기">
</p>

레이저, 폭발, 알림음, 악기 소리까지 수백 가지 프리셋을 검색해 고르고, 주파수 · 길이 · 감쇠 같은 값을 바꿔 바로 들어 볼 수 있어요. 마음에 든 설정은 '내 프리셋'으로 저장해요. 게임이나 영상에 넣을 효과음을 직접 만들 때 좋아요.

### 07. 오디오 파일을 끌어다 놓으면 새 탭으로 바로 열기

<p align="center">
<img src="images/08-drag-and-drop.webp" width="100%" alt="오디오 파일을 끌어다 놓으면 새 탭으로 바로 열기">
</p>

탐색기에서 오디오 파일을 창으로 끌어다 놓기만 하면 각각 새 탭으로 열려요. 여러 파일을 한꺼번에 놓아도 돼요.

### 08. 키보드 단축키를 한곳에서 확인하고 원하는 대로 변경

<p align="center">
<img src="images/09-keyboard-shortcuts.webp" width="100%" alt="키보드 단축키를 한곳에서 확인하고 원하는 대로 변경">
</p>

메뉴와 단축키를 한 표에서 보고, 원하는 키로 바꾸거나 기본값으로 되돌릴 수 있어요. 내 설정을 프리셋으로 저장해 두었다가 언제든 다시 불러올 수 있어요.

### 09. 예기치 않게 종료되어도 저장하지 않은 작업을 자동 복구

<p align="center">
<img src="images/10-autosave-recovery.webp" width="100%" alt="예기치 않게 종료되어도 저장하지 않은 작업을 자동 복구">
</p>

작업 중에 앱이 갑자기 꺼져도 걱정 마세요. 다음에 켜면 저장하지 않은 작업을 찾아서 열지, 나중에 정할지, 버릴지 물어봐요. '나중에'를 고르면 복구 파일은 그대로 남아 다음 실행 때 다시 알려 줘요.

## 2.0에서 새로워진 것

2.0은 일상적인 편집을 더 쉽고, 더 빠르고, 더 안전하게 만드는 데 집중한 대규모 업데이트입니다.

- **MIDI 파일을 파형으로.** MIDI 파일(.mid)을 열면 기본 제공 음원으로 연주한 소리를 파형으로 보여 주며, 일반 오디오처럼 편집하고 WAV·MP3 등으로 저장할 수 있습니다.
- **초보자를 위한 도움말.** 앱 내 도움말을 쉬운 말로 새로 썼습니다. 파일 열기, 원하는 구간 선택, 편집, 저장까지 순서대로 따라 할 수 있습니다.
- **드래그 앤 드롭.** 오디오 파일을 창에 끌어다 놓기만 하면 바로 열립니다.
- **더 많은 형식.** Ogg Vorbis(.ogg) 파일을 5.1, 7.1 서라운드까지 열고 저장할 수 있으며, FLAC은 이제 모든 Windows 에디션에서 동작합니다.
- **사용자 정의 단축키.** 원하는 작업 방식에 맞게 단축키를 직접 지정할 수 있습니다.
- **긴 파일과 긴 녹음도 매끄럽게.** 긴 파일을 열고 저장하는 속도가 눈에 띄게 빨라졌고, 녹음하는 동안 바로 기록해 긴 작업에서도 앱이 느려지지 않습니다.
- **자동 파일 복구.** 앱이 예기치 않게 종료돼도 다음 실행 때 작업하던 내용을 되살립니다.
- **USB 오디오 개선.** USB 마이크나 스피커를 연결하거나 교체할 때 더 안정적으로 인식합니다.
- **SFX 생성기 사용자 프리셋 2세대.** 프리셋 수가 늘고 음질도 좋아졌습니다.
- **새로워진 화면.** 툴바 아이콘을 더 간결하고 선명하게 다듬고, 라이트/다크 테마에 맞춰 테마 색을 다시 조정했습니다.
- 앱 전반의 안정성과 신뢰성 개선.

## 전체 기능 한눈에

- 지원 오디오 파일을 열고 전체 채널 또는 한 채널만 선택해 편집
- MIDI 파일(.mid, .midi, .rmi)을 기본 제공 음원으로 연주해 편집 가능한 파형으로 열기
- 녹음에서 음표를 분석해 악보로 보고, 고친 뒤 MIDI 파일로 저장
- 선택 구간에 잘라내기, 복사, 붙여넣기, 삭제, 음소거, 페이드, 실행 취소 및 다시 실행
- 하나의 작업공간에서 재생, 반복 재생, 녹음, 저장 및 내보내기
- 리전, 큐, 레이어, 스펙트로그램 패널을 이용한 탐색과 시각 분석
- DC 오프셋 제거, 필터, 이퀄라이저, 베이스 셸프, 컴프레서, 볼륨, 정규화 및 하드 클립
- 재생 속도 변경, 리샘플 및 SFX 생성기
- 자동 크로스페이드, 스냅, 짧은 페이드로 편집 지점의 클릭음 감소
- 저사양 PC 최적화와 단계적 파형 정밀화로 긴 파일도 반응성 유지

인터페이스와 앱 내 도움말은 현지화되어 있습니다. 일부 표준 오디오 효과명, 파일 형식명 및 기술 용어는 영어로 표시됩니다.

## 필요 사항

지원 형식: WAV, AIFF, FLAC, Ogg Vorbis, MP3, WMA. MP3와 WMA는 대부분의 Windows 에디션에 기본 포함된 Windows 미디어 구성 요소를 사용하며, Windows N 에디션에서는 설정 > 앱 > 선택적 기능에서 무료 Media Feature Pack을 설치하면 사용할 수 있습니다. WAV, AIFF, FLAC, Ogg Vorbis는 항상 동작합니다. 앱 내 도움말 뷰어는 Microsoft Edge WebView2 Runtime을 사용합니다. 이 런타임은 Windows 11에 기본 포함되어 있고 대부분의 Windows 10 PC에 이미 설치되어 있으며, 없더라도 도움말 뷰어만 영향을 받고 오디오 편집은 그대로 동작합니다.
