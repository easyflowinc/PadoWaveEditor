# Pado Wave Editor

<p align="center">

**Windows용 전문 오디오 파형 편집기**

빠르고 정밀한 오디오 편집을 지원하는 Windows용 전문 편집기입니다.
파형 분석, 스펙트로그램 시각화, 전문 오디오 필터 및 녹음 기능을 통해 다양한 오디오 작업을 효율적으로 수행할 수 있습니다.

</p>

---

# 다운로드

최신 설치 프로그램은 **Releases**에서 다운로드할 수 있습니다.

설치 프로그램을 실행하면 **Microsoft Store**가 자동으로 열리며, 최신 공식 버전의 **Pado Wave Editor**가 설치됩니다.

---

# 주요 기능

* 전문 파형(Waveform) 편집
* 고성능 오디오 처리 엔진
* 다중 채널 편집
* 하이패스(High-pass) / 로우패스(Low-pass) 필터
* 스펙트로그램 분석
* FFT 주파수 분석
* 정밀 확대/축소(Zoom)
* 실시간 재생
* 오디오 녹음
* 대용량 오디오 파일 지원
* Windows 10 및 Windows 11 최적화
* Microsoft Store를 통한 자동 업데이트

# 설치 방법

1. **Pado.Wave.Editor.Installer.exe**를 다운로드합니다.
2. 설치 프로그램을 실행합니다.
3. Microsoft Store가 자동으로 열립니다.
4. **Pado Wave Editor**를 설치합니다.
