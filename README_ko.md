# Pado Wave Editor

<p align="center">

## Windows용 전문 오디오 편집기

**Pado Wave Editor**는 Windows 환경에서 사용할 수 있는 전문 **오디오 편집기(Audio Editor)**이자 **파형 편집기(Wave Editor / Waveform Editor)**입니다.

WAV, MP3, PCM 등 다양한 오디오 파일을 빠르고 정확하게 편집할 수 있으며, 실시간 **파형(Waveform) 표시**, **스펙트로그램(Spectrogram) 분석**, **FFT 주파수 분석**, **오디오 처리(Audio Processing)** 및 **신호 처리(Signal Processing)** 기능을 제공합니다.

음성 편집, 음악 편집, 팟캐스트 제작, 오디오 복원, 방송 제작, 연구 및 음향 분석 등 다양한 작업에 적합하도록 설계되었으며, 직관적인 인터페이스와 고성능 오디오 엔진을 통해 대용량 오디오도 안정적으로 처리할 수 있습니다.

</p>

# 다운로드

최신 설치 프로그램은 **Releases**에서 다운로드할 수 있습니다.

설치 프로그램을 실행하면 **Microsoft Store**가 자동으로 열리며, 항상 최신 공식 버전의 **Pado Wave Editor**가 설치됩니다.

---

# 주요 기능

* 전문 오디오 편집(Audio Editing)
* 정밀 파형(Waveform) 편집
* 고성능 오디오 처리 엔진
* 다중 채널 오디오 편집
* 실시간 파형(Waveform) 표시
* 스펙트로그램(Spectrogram) 분석
* FFT 주파수 분석
* 오디오 분석(Audio Analysis)
* 오디오 처리(Audio Processing)
* 신호 처리(Signal Processing)
* 하이패스(High-pass) / 로우패스(Low-pass) 필터
* 정밀 확대/축소(Zoom)
* 실시간 재생
* 오디오 녹음
* WAV / MP3 / PCM 파일 지원
* 대용량 오디오 파일 최적화
* Windows 10 및 Windows 11 최적화
* Microsoft Store를 통한 자동 업데이트

# 설치 방법

1. **Pado.Wave.Editor.Installer.exe**를 다운로드합니다.

3. Microsoft Store가 자동으로 열립니다.
4. **Pado Wave Editor**를 설치합니다.
