# Pado Wave Editor

<p align="center">

**Профессиональный редактор звуковых волн для Windows**

Быстрый, точный и мощный аудиоредактор для Windows.
Редактируйте аудиофайлы с помощью профессиональных инструментов, включая редактирование формы звуковой волны, спектрограмму, FFT-анализ, аудиофильтры и средства записи звука.

</p>

---

# Загрузка

Загрузите последнюю версию установщика со страницы **Releases**.

После запуска установщика автоматически откроется **Microsoft Store** и будет установлена последняя официальная версия **Pado Wave Editor**.

---

# Возможности

* Профессиональное редактирование звуковой волны
* Высокопроизводительный аудиодвижок
* Многоканальное редактирование
* Фильтры верхних и нижних частот (High-pass / Low-pass)
* Анализ спектрограммы
* FFT-анализ частот
* Точное масштабирование
* Воспроизведение в реальном времени
* Запись звука
* Поддержка больших аудиофайлов
* Оптимизировано для Windows 10 и Windows 11
* Автоматические обновления через Microsoft Store

# Установка

1. Загрузите **Pado.Wave.Editor.Installer.exe**.
2. Запустите установщик.
3. Microsoft Store откроется автоматически.
4. Установите **Pado Wave Editor**.
