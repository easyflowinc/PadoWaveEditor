# Pado Wave Editor

<p align="center">

**Editor profissional de formas de onda de áudio para Windows**

Um editor de áudio rápido, preciso e poderoso para Windows.
Edite ficheiros de áudio com funcionalidades profissionais, incluindo edição de formas de onda, visualização por espectrograma, análise de frequência FFT, filtros de áudio e ferramentas de gravação.

</p>

---

# Transferência

Transfira o instalador mais recente na página **Releases**.

Ao executar o instalador, a **Microsoft Store** será aberta automaticamente e instalará a versão oficial mais recente do **Pado Wave Editor**.

---

# Funcionalidades

* Edição profissional de formas de onda
* Motor de processamento de áudio de elevado desempenho
* Edição multicanal
* Filtros passa-alto e passa-baixo
* Análise por espectrograma
* Análise de frequência FFT
* Zoom de elevada precisão
* Reprodução em tempo real
* Gravação de áudio
* Suporte para ficheiros de áudio de grandes dimensões
* Otimizado para Windows 10 e Windows 11
* Atualizações automáticas através da Microsoft Store

# Instalação

1. Transfira **Pado.Wave.Editor.Installer.exe**.
2. Execute o instalador.

4. Instale o **Pado Wave Editor**.
