# Pado Wave Editor

<p align="center">

**Éditeur professionnel de formes d'onde audio pour Windows**

Un éditeur audio rapide, précis et performant pour Windows.
Modifiez vos fichiers audio grâce à des fonctionnalités professionnelles telles que l'édition de formes d'onde, la visualisation par spectrogramme, l'analyse de fréquence FFT, les filtres audio et les outils d'enregistrement.

</p>

---

# Téléchargement

Téléchargez le dernier programme d'installation depuis la page **Releases**.

L'exécution du programme d'installation ouvre automatiquement le **Microsoft Store** et installe la dernière version officielle de **Pado Wave Editor**.

---

# Fonctionnalités

* Édition professionnelle des formes d'onde
* Moteur de traitement audio haute performance
* Édition multicanal
* Filtres passe-haut et passe-bas
* Analyse par spectrogramme
* Analyse de fréquence FFT
* Zoom de haute précision
* Lecture en temps réel
* Enregistrement audio
* Prise en charge des fichiers audio volumineux
* Optimisé pour Windows 10 et Windows 11
* Mises à jour automatiques via Microsoft Store

# Installation

1. Téléchargez **Pado.Wave.Editor.Installer.exe**.
2. Exécutez le programme d'installation.
3. Le Microsoft Store s'ouvre automatiquement.
4. Installez **Pado Wave Editor**.
