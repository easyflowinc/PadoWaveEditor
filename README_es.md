# Pado Wave Editor

<p align="center">

**Editor profesional de formas de onda de audio para Windows**

Un editor de audio rápido, preciso y potente para Windows.
Edite archivos de audio con funciones profesionales como edición de formas de onda, visualización de espectrogramas, análisis de frecuencia FFT, filtros de audio y herramientas de grabación.

</p>

---

# Descarga

Descargue el instalador más reciente desde la página **Releases**.

Al ejecutar el instalador, **Microsoft Store** se abrirá automáticamente e instalará la versión oficial más reciente de **Pado Wave Editor**.

---

# Características

* Edición profesional de formas de onda
* Motor de procesamiento de audio de alto rendimiento
* Edición multicanal
* Filtros de paso alto y paso bajo
* Análisis de espectrograma
* Análisis de frecuencia FFT
* Zoom de alta precisión
* Reproducción en tiempo real
* Grabación de audio
* Compatibilidad con archivos de audio de gran tamaño
* Optimizado para Windows 10 y Windows 11
* Actualizaciones automáticas mediante Microsoft Store

# Instalación

1. Descargue **Pado.Wave.Editor.Installer.exe**.
2. Ejecute el instalador.
3. Microsoft Store se abrirá automáticamente.
4. Instale **Pado Wave Editor**.
