# Pado Wave Editor

<p align="center">

**Professioneller Audio-Wellenform-Editor für Windows**

Ein schneller, präziser und leistungsstarker Audio-Editor für Windows.
Bearbeiten Sie Audiodateien mit professionellen Funktionen wie Wellenformbearbeitung, Spektrogramm-Visualisierung, FFT-Frequenzanalyse, Audiofiltern und Aufnahmewerkzeugen.

</p>

---

# Download

Laden Sie das neueste Installationsprogramm von der **Releases**-Seite herunter.

Nach dem Start des Installationsprogramms wird der **Microsoft Store** automatisch geöffnet und die aktuelle offizielle Version von **Pado Wave Editor** installiert.

---

# Funktionen

* Professionelle Wellenformbearbeitung
* Leistungsstarke Audio-Engine
* Mehrkanalbearbeitung
* Hochpass- und Tiefpassfilter
* Spektrogramm-Analyse
* FFT-Frequenzanalyse
* Präzises Zoomen
* Echtzeit-Wiedergabe
* Audioaufnahme
* Unterstützung für große Audiodateien
* Optimiert für Windows 10 und Windows 11
* Automatische Updates über den Microsoft Store

# Installation

1. Laden Sie **Pado.Wave.Editor.Installer.exe** herunter.
2. Starten Sie das Installationsprogramm.
3. Der Microsoft Store wird automatisch geöffnet.
4. Installieren Sie **Pado Wave Editor**.
