# Pado Wave Editor

<p align="center">

**適用於 Windows 的專業音訊波形編輯器**

一款快速、精確且功能強大的 Windows 音訊編輯軟體。
提供波形編輯、頻譜圖（Spectrogram）分析、FFT 頻率分析、專業音訊濾波器以及錄音功能，協助您高效完成各種音訊處理工作。

</p>

---

# 下載

請從 **Releases** 頁面下載最新安裝程式。

執行安裝程式後，**Microsoft Store** 將自動開啟，並安裝最新官方版本的 **Pado Wave Editor**。

---

# 主要功能

* 專業波形編輯
* 高效能音訊處理引擎
* 多聲道編輯
* 高通／低通濾波器
* 頻譜圖分析（Spectrogram）
* FFT 頻率分析
* 精確縮放
* 即時播放
* 音訊錄製
* 支援大型音訊檔案
* 針對 Windows 10 與 Windows 11 最佳化
* 透過 Microsoft Store 自動更新

# 安裝方式

1. 下載 **Pado.Wave.Editor.Installer.exe**。
2. 執行安裝程式。
3. Microsoft Store 將自動開啟。
4. 安裝 **Pado Wave Editor**。
