# Pado Wave Editor 2.0

### 一邊看著聲音，一邊剪下、貼上、修飾——免費的音訊編輯器

人聲錄音、唱歌練習、替影片配的音效，通通可以。把檔案拖進視窗，波形立刻出現；拖曳選取想要的片段，剪掉、加個淡入淡出、儲存，就完成了。流程保持簡單，第一次用也不會迷路。

## 這些時候最適合

- 🎙️ **整理人聲錄音** — 從 Podcast、簡報和語音備忘錄中剪掉口誤和過長的停頓，並讓音量更平均。
- 🎧 **比較兩個版本** — 把兩個檔案左右並排，輪流循環同一段，留下比較好的那一個。
- 🎹 **把 MIDI 變成音訊** — 開啟 MIDI 樂曲，立即演奏並顯示為波形。修飾後儲存為 WAV 或 MP3。
- 🎮 **遊戲與影片音效** — 從預設中挑選雷射、爆炸、提示音等音效，點幾下就能做出自己的聲音。
- 🎼 **把演奏變成樂譜** — 從錄下的演奏中找出音符並以樂譜顯示。點選音符，用方向鍵修改位置、音高或時值（或按 Delete 刪除），然後儲存為 MIDI 檔案。
- 🔍 **看清聲音的內部** — 用頻譜圖和頻率分析，直接用眼睛找到雜音和爆音的位置。

## 三步驟搞定

1. **開啟** — 把檔案拖進視窗或按 Ctrl+O。WAV、MP3、FLAC、OGG、MIDI 都能開啟。
2. **選取並編輯** — 在波形上拖曳選取片段，然後剪下、淡入淡出或加上效果。弄錯了？按 Ctrl+Z。
3. **儲存** — 按 Ctrl+S 儲存，或匯出成需要的格式。

## 功能導覽

### 01. 在清楚的多聲道波形工作區中編輯音訊

<p align="center">
<img src="images/03-main-workspace.webp" width="100%" alt="在清楚的多聲道波形工作區中編輯音訊">
</p>

在上方的大波形中編輯，下方的概覽列讓你一眼看出目前位在整個檔案的哪裡。檔案資訊、播放位置和選取長度一直顯示在波形正下方的資訊列。長檔案也會先快速顯示波形，再補上細節，不必久等。

### 02. 同時編輯所有聲道，或逐一選取聲道進行精細編輯

<p align="center">
<img src="images/05-channel-editing.webp" width="100%" alt="同時編輯所有聲道，或逐一選取聲道進行精細編輯">
</p>

立體聲音訊可以同時選取左（上）右（下）兩個聲道，也可以只選其中一個。只清除一側的雜音，或只替一個聲道加淡入淡出，精細修改很輕鬆。

### 03. 以內建音色庫演奏 MIDI 檔案，並以波形開啟和編輯

<p align="center">
<img src="images/02-midi-as-waveform.webp" width="100%" alt="以內建音色庫演奏 MIDI 檔案，並以波形開啟和編輯">
</p>

MIDI 檔案（.mid、.midi、.rmi）裡裝的是音符，不是聲音。開啟後，應用程式以內建音色庫（MuseScore General）演奏並顯示為波形，你可以像一般音訊一樣剪下、加效果，並儲存為 WAV 或 MP3。更喜歡別的 SF2 或 SF3 音色庫？在「選項」中切換即可。

### 04. 使用效果、濾波器與分析工具調整並檢查聲音

<p align="center">
<img src="images/04-effects-analysis.webp" width="100%" alt="使用效果、濾波器與分析工具調整並檢查聲音">
</p>

等化器、濾波器、壓縮器、正規化等效果可以只套用到選取的片段。拖曳圖上的點來塑造聲音，等化器設定最多可儲存 10 組，之後再載入。

### 05. 透過區域、提示點、圖層與頻譜圖面板快速定位

<p align="center">
<img src="images/06-panels.webp" width="100%" alt="透過區域、提示點、圖層與頻譜圖面板快速定位">
</p>

可命名、可上色的區段，標記位置的提示點，可開關處理結果進行比較的圖層，讓你在長檔案中也不會迷路。頻譜圖以顏色依頻率顯示聲音，雜音和爆音一眼就能找到。

### 06. 使用數百個以公式為基礎的預設產生音效

<p align="center">
<img src="images/07-sfx-generator.webp" width="100%" alt="使用數百個以公式為基礎的預設產生音效">
</p>

搜尋數百個預設——雷射、爆炸、提示音，甚至樂器聲——調整頻率、長度、衰減等參數並立即試聽。喜歡的設定可以儲存為「我的預設」。非常適合替遊戲和影片自製音效。

### 07. 將音訊檔案拖放到編輯器中，在新分頁中開啟

<p align="center">
<img src="images/08-drag-and-drop.webp" width="100%" alt="將音訊檔案拖放到編輯器中，在新分頁中開啟">
</p>

只要把音訊檔案從檔案總管拖到視窗上，每個檔案都會在新分頁中開啟。也可以一次拖入多個檔案。

### 08. 檢視並自訂鍵盤快速鍵

<p align="center">
<img src="images/09-keyboard-shortcuts.webp" width="100%" alt="檢視並自訂鍵盤快速鍵">
</p>

在一張表中查看選單和快速鍵，可改成任意按鍵，也可還原預設值。把自己的設定儲存為預設，隨時都能再載入。

### 09. 意外關閉後自動復原未儲存的工作

<p align="center">
<img src="images/10-autosave-recovery.webp" width="100%" alt="意外關閉後自動復原未儲存的工作">
</p>

工作時應用程式意外關閉也別慌。下次啟動時，它會找到未儲存的工作，詢問你要開啟、稍後決定還是捨棄。選擇「稍後」，復原檔案會保留，下次啟動時再次提醒。

## 2.0 新功能

2.0 是一次重要更新，讓日常編輯更簡單、更快速、更可靠。

- **MIDI 檔案變波形。** 開啟 MIDI 檔案（.mid）時，應用程式以內建音色庫演奏並以波形顯示，可像一般音訊一樣編輯，並儲存為 WAV、MP3 等格式。
- **適合新手的說明。** 應用程式內說明以淺白語言重寫，逐步引導您開啟檔案、選取片段、編輯與儲存。
- **拖放開啟。** 將音訊檔案直接拖曳到視窗即可開啟。
- **更多格式。** 可以開啟和儲存 Ogg Vorbis (.ogg) 檔案，包括 5.1 與 7.1 環繞音效；FLAC 現在可在所有 Windows 版本上使用。
- **自訂快速鍵。** 可依照自己的使用習慣重新指定快速鍵。
- **長檔案與長時間錄音更流暢。** 開啟和儲存長檔案明顯更快，錄音時即時寫入磁碟，長時間作業也不會變慢。
- **自動檔案復原。** 應用程式意外關閉後，下次啟動時可復原您的工作內容。
- **USB 音訊改進。** 連接或更換 USB 麥克風與喇叭時辨識更穩定。
- **SFX產生器使用者預設集第二代。** 預設集數量更多，音質更好。
- **全新外觀。** 工具列圖示更簡潔清晰，佈景主題配色針對淺色與深色模式重新調校。
- 全面提升應用程式的穩定性與可靠性。

## 全部功能一覽

- 開啟支援的音訊檔案，並可同時編輯全部聲道或單獨編輯一個聲道
- 以內建音色庫演奏 MIDI 檔案（.mid、.midi、.rmi），並以可編輯的波形開啟
- 分析錄音中的音符，以樂譜顯示並修改，然後儲存為 MIDI 檔案
- 對選取音訊執行剪下、複製、貼上、刪除、靜音、淡化、復原與重做
- 在同一工作區中完成播放、循環播放、錄音、儲存與匯出
- 使用區域、提示點、圖層與頻譜圖面板進行導覽和視覺分析
- 提供DC偏移移除、濾波、等化、低頻擱架、壓縮、音量、正規化與硬限制
- 變更播放速度、重新取樣並使用SFX產生器建立聲音
- 透過自動交叉淡化、吸附與短淡化減少編輯點的喀聲
- 透過低階電腦最佳化與分階段波形細化維持長檔案操作順暢

介面與應用程式內說明已在地化。部分標準音訊效果名稱、檔案格式名稱和技術術語仍以英文顯示。

## 系統需求

支援的格式：WAV、AIFF、FLAC、Ogg Vorbis、MP3、WMA。MP3 與 WMA 使用大多數 Windows 版本內建的 Windows 媒體元件；在 Windows N 版本中，請於「設定 > 應用程式 > 選用功能」安裝免費的 Media Feature Pack 後即可使用。WAV、AIFF、FLAC 與 Ogg Vorbis 一律可用。應用程式內的說明檢視器使用 Microsoft Edge WebView2 Runtime，它隨 Windows 11 提供，且大多數 Windows 10 電腦已預先安裝；若缺少此執行階段，僅說明檢視器受影響，音訊編輯不受影響。
