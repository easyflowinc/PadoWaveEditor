# Pado Wave Editor 2.0

### 音を目で見ながら、切って、貼って、仕上げる。無料のオーディオエディター

声の録音、歌の練習ファイル、動画に入れる効果音まで。ファイルをウィンドウにドラッグすればすぐに波形が表示され、使いたい範囲をドラッグで選んでカット、フェードをかけて保存すれば完成です。初めてでも迷わないよう、流れはシンプルにしています。

**無料** · **Windows 10 · 11** · **WAV · MP3 · FLAC · OGG · MIDI** · **14言語** · **ライト/ダークテーマ**

[Microsoft Store から入手](https://apps.microsoft.com/detail/9nj5928hw9pw) · [詳しい説明とよくある質問](https://easyflow.co.kr/F/Doc/PadoWaveEditor/ja) · [以前のバージョン(1.0)の紹介](v1.0/README_ja.md)

## こんなときにぴったり

- 🎙️ **声の録音を整える** — ポッドキャストやプレゼン、ボイスメモから言い間違いや長い無音をカットし、音量をそろえます。
- 🎧 **2つのテイクを比べる** — 2つのファイルを左右に並べ、同じ区間を交互に聴いて良いほうを選べます。
- 🎹 **MIDIをオーディオに** — MIDI曲を開くとすぐに演奏されて波形になります。仕上げてWAVやMP3で保存しましょう。
- 🎮 **ゲーム・動画の効果音** — レーザー、爆発、通知音などの効果音をプリセットから選び、数クリックで作れます。
- 🎼 **演奏を楽譜に** — 録音した演奏から音符を見つけて楽譜で表示します。音符をクリックして矢印キーで位置・音の高さ・長さを直すか、Deleteで消してから、MIDIファイルとして保存します。
- 🔍 **音の中をのぞく** — スペクトログラムと周波数解析で、ノイズやプチッという音の場所を目で探せます。

## 3ステップで完成

1. **開く** — ファイルをウィンドウにドラッグするか、Ctrl+O。WAV、MP3、FLAC、OGG、MIDIすべて開けます。
2. **選んで編集** — 波形をドラッグして範囲を選び、カット、フェード、エフェクトをかけます。失敗してもCtrl+Zで戻せます。
3. **保存** — Ctrl+Sで保存するか、必要な形式で書き出します。

## 機能ツアー

### 01. マルチチャンネル波形を見ながら編集できるメインワークスペース

<p align="center">
<img src="images/03-main-workspace.webp" width="100%" alt="マルチチャンネル波形を見ながら編集できるメインワークスペース">
</p>

上の大きな波形で編集し、下の概要バーでファイル全体のどこを見ているかがひと目でわかります。ファイル情報、再生位置、選択の長さは波形のすぐ下の情報バーに常に表示されます。長いファイルもまず波形をすばやく表示し、細部はあとから描き足すので、長く待つことはありません。

### 02. 全チャンネルをまとめて、または1チャンネルずつ選択して編集

<p align="center">
<img src="images/05-channel-editing.webp" width="100%" alt="全チャンネルをまとめて、または1チャンネルずつ選択して編集">
</p>

ステレオなら左(上)と右(下)のチャンネルをまとめて選ぶことも、片方だけ選ぶこともできます。片側だけに入ったノイズを消したり、1チャンネルだけにフェードをかけたりと、細かな手直しが簡単です。

### 03. MIDIファイルを内蔵サウンドフォントで演奏し、波形として開いて編集

<p align="center">
<img src="images/02-midi-as-waveform.webp" width="100%" alt="MIDIファイルを内蔵サウンドフォントで演奏し、波形として開いて編集">
</p>

MIDIファイル(.mid・.midi・.rmi)に入っているのは音ではなく音符です。開くと内蔵のサウンドフォント(MuseScore General)で演奏して波形で表示するので、普通のオーディオと同じようにカットやエフェクトをかけ、WAVやMP3で保存できます。好みのSF2・SF3サウンドフォントがあれば、オプションで切り替えられます。

### 04. エフェクト、フィルター、解析ツールでサウンドを調整・確認

<p align="center">
<img src="images/04-effects-analysis.webp" width="100%" alt="エフェクト、フィルター、解析ツールでサウンドを調整・確認">
</p>

イコライザー、フィルター、コンプレッサー、ノーマライズなどのエフェクトを、選んだ範囲だけにかけられます。グラフの点をドラッグして音を変え、イコライザーの設定は10個まで保存して後で呼び出せます。

### 05. リージョン、キュー、レイヤー、スペクトログラムで素早く移動

<p align="center">
<img src="images/06-panels.webp" width="100%" alt="リージョン、キュー、レイヤー、スペクトログラムで素早く移動">
</p>

名前と色を付けられるリージョン、位置を示すキュー、処理をオン・オフして比べられるレイヤーで、長いファイルでも迷いません。スペクトログラムは音を周波数ごとの色で見せるので、ノイズやプチッという音を目で探せます。

### 06. 数百種類の数式ベースのプリセットで効果音を作成

<p align="center">
<img src="images/07-sfx-generator.webp" width="100%" alt="数百種類の数式ベースのプリセットで効果音を作成">
</p>

レーザー、爆発、アラート、楽器の音まで、数百のプリセットを検索して選び、周波数・長さ・減衰などを変えてすぐに試聴できます。気に入った設定は「マイプリセット」に保存。ゲームや動画用の効果音を自分で作るのに最適です。

### 07. 音声ファイルをドラッグ＆ドロップして新しいタブで開く

<p align="center">
<img src="images/08-drag-and-drop.webp" width="100%" alt="音声ファイルをドラッグ＆ドロップして新しいタブで開く">
</p>

エクスプローラーからオーディオファイルをウィンドウにドラッグするだけで、それぞれ新しいタブで開きます。複数のファイルをまとめてドロップしてもOKです。

### 08. キーボードショートカットを一覧で確認し自由にカスタマイズ

<p align="center">
<img src="images/09-keyboard-shortcuts.webp" width="100%" alt="キーボードショートカットを一覧で確認し自由にカスタマイズ">
</p>

メニューとショートカットを1つの表で確認し、好きなキーに変えたり既定値に戻したりできます。自分の設定をプリセットとして保存し、いつでも読み込めます。

### 09. 予期しない終了後も未保存の作業を自動で復元

<p align="center">
<img src="images/10-autosave-recovery.webp" width="100%" alt="予期しない終了後も未保存の作業を自動で復元">
</p>

作業中にアプリが突然終了しても大丈夫。次に起動したとき、保存していない作業を見つけて、開くか、後で決めるか、破棄するかを尋ねます。「後で」を選ぶと復元ファイルは残り、次回の起動時にもう一度案内されます。

## 2.0の新機能

バージョン2.0は、日常の編集をより簡単に、より速く、より安心して行えるようにした大型アップデートです。

- **MIDIファイルを波形で。** MIDIファイル（.mid）を開くと内蔵のサウンドフォントで演奏した音を波形で表示し、通常の音声と同じように編集してWAVやMP3などで保存できます。
- **初心者向けヘルプ。** アプリ内ヘルプをやさしい言葉で書き直し、ファイルを開く、範囲を選ぶ、編集する、保存するまでを順番に案内します。
- **ドラッグ＆ドロップ。** 音声ファイルをウィンドウにドロップするだけで開けます。
- **対応形式の追加。** Ogg Vorbis (.ogg) ファイルを 5.1 / 7.1 サラウンドも含めて開いて保存でき、FLAC はすべての Windows エディションで使えるようになりました。
- **ショートカットのカスタマイズ。** 自分の作業に合わせてキー割り当てを変更できます。
- **長いファイルと長時間の録音も快適に。** 長いファイルの読み込みと保存が大幅に速くなり、録音中はその場で書き込むため長時間の作業でも動作が重くなりません。
- **自動ファイル復旧。** アプリが予期せず終了しても、次回起動時に作業内容を復元します。
- **USBオーディオの改善。** USBマイクやスピーカーの接続・差し替えをより確実に認識します。
- **SFXジェネレーターのユーザープリセット第2世代。** プリセット数が増え、音質も向上しました。
- **新しい外観。** ツールバーアイコンをすっきり鮮明にし、ライト／ダークテーマに合わせて配色を調整しました。
- アプリ全体の安定性と信頼性の向上。

## 全機能をひと目で

- 対応する音声ファイルを開き、全チャンネルまたは片方のチャンネルを編集
- MIDIファイル（.mid、.midi、.rmi）を内蔵サウンドフォントで演奏し、編集できる波形として開く
- 録音の音符を解析して楽譜で表示し、修正してMIDIファイルとして保存
- 選択範囲のカット、コピー、貼り付け、削除、ミュート、フェード、元に戻す、やり直し
- 1つの作業画面で再生、ループ、録音、保存、書き出し
- リージョン、キュー、レイヤー、スペクトログラムによる移動と視覚解析
- DCオフセット除去、フィルター、EQ、ベースシェルフ、コンプレッサー、音量、ノーマライズ、ハードクリップ
- 再生速度変更、リサンプル、SFXジェネレーター
- 自動クロスフェード、スナップ、短いフェードで編集点のクリック音を低減
- 低スペックPC最適化と段階的な波形更新で長いファイルにも対応

インターフェイスとアプリ内ヘルプはローカライズされています。一部の標準的な音声エフェクト名、ファイル形式名、技術用語は英語のまま表示されます。

## 必要条件

対応形式: WAV、AIFF、FLAC、Ogg Vorbis、MP3、WMA。MP3 と WMA は、ほとんどの Windows エディションに含まれる Windows メディア コンポーネントを使用します。Windows N エディションでは、設定 > アプリ > オプション機能 から無料の Media Feature Pack をインストールすると利用できます。WAV、AIFF、FLAC、Ogg Vorbis は常に利用できます。アプリ内のヘルプ ビューアーは Microsoft Edge WebView2 Runtime を使用します。これは Windows 11 に含まれ、ほとんどの Windows 10 PC には既にインストールされています。ない場合もヘルプ ビューアーのみが影響を受け、オーディオ編集はそのまま動作します。
