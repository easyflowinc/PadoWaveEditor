# Pado Wave Editor

<p align="center">

**Windows向けプロフェッショナル オーディオ波形エディター**

高速・高精度・高機能な Windows 用オーディオ編集ソフトです。
波形編集、スペクトログラム解析、FFT 周波数解析、プロフェッショナルなオーディオフィルター、録音機能などを搭載し、効率的なオーディオ編集を実現します。

</p>

---

# ダウンロード

最新のインストーラーは **Releases** ページからダウンロードできます。

インストーラーを実行すると **Microsoft Store** が自動的に起動し、最新の公式版 **Pado Wave Editor** がインストールされます。

---

# 主な機能

* プロフェッショナル波形編集
* 高性能オーディオ処理エンジン
* マルチチャンネル編集
* ハイパス / ローパスフィルター
* スペクトログラム解析
* FFT 周波数解析
* 高精度ズーム
* リアルタイム再生
* オーディオ録音
* 大容量オーディオファイル対応
* Windows 10 / Windows 11 に最適化
* Microsoft Store による自動アップデート

# インストール方法

1. **Pado.Wave.Editor.Installer.exe** をダウンロードします。
2. インストーラーを実行します。
3. Microsoft Store が自動的に開きます。
4. **Pado Wave Editor** をインストールします。

---
